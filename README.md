# Miss Mae Revivals Flip Companion

A mobile-first, front-end prototype for planning a furniture flip from first look to final listing. The app uses mock data and does not connect to a database, marketplace, or course API.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` for a production build.

The generated dresser image and selected product images are in `public/images`. Product imagery came from the repository's Favorites archive. Product links open public product pages; course buttons open the Miss Mae Revivals Stan Store.
