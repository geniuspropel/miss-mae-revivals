# Miss Mae Revivals Flip Companion

A mobile-first, front-end prototype that follows one sample Mid-Century Dresser from purchase to listing. The app uses deterministic demo data and does not connect to a database, marketplace, or course API.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` for a production build.

Selections, checklists, owned supplies, and listing drafts are saved in browser local storage. **Reset Demo** in My Flips restores the starting state. Lesson buttons open in-app video preview placeholders; playback is not connected.

The generated photography and selected product images are in `public/images`. Product imagery came from the repository's Favorites archive. Product links open public product pages. The refinishing guidance, tips, product suggestions, and lesson titles are sample content for creator review.
